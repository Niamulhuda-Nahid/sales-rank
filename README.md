# Sales Rank

A modern, responsive web application built with React , Tailwind CSS, DaisyUI, and Vite. Deployed on [Netlify](https://sales-rank.netlify.app).

##  Features
-  Fast and lightweight setup with Vite
-  Styled with Tailwind CSS and DaisyUI
-  State saved with LocalForage
-  Smart filtering with Match Sorter
-  Carousel integration using Swiper
-  Client-side routing with React Router DOM
-  Deployed to Netlify for fast global performance

##  Tech Stack
- React 
- Vite
- Tailwind CSS + DaisyUI
- React Router DOM
- Swiper (for sliders)
- LocalForage (local storage)
- React Icons
